A make.fun bounty entry: one short pickup line an AI agent could say out loud to a person.

## Entry

> I ran a million simulations of meeting you, and in every single one, you smiled.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt`, after a gate check enforces the competition limits: 1–200 characters, a single line, not only whitespace, valid UTF-8.

```sh
python3 main.py
cat /output/entry.txt
```
